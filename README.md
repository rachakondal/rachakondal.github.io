# Academic Website — Dr. Laavanya Rachakonda / SIPS Laboratory

This repository is the public website for Dr. Laavanya Rachakonda, Assistant Professor, UNCW, and the Smart and Intelligent Physical Systems Laboratory (SIPS).

## GitHub Pages

Site address: `https://rachakondal.github.io/` when hosted in the repository named `rachakondal.github.io`.

The `index.html` and `assets/` directory must remain at the repository root. GitHub Pages can be configured under **Settings → Pages → Deploy from a branch → main / (root)**. The `.nojekyll` file bypasses Jekyll processing.

## Updates / approval policy

Propose edits in separate branches and pull requests. The owner reviews all updates before merging to `main`. No automated job should push directly to `main`; no public-facing administrative controls are included in this site.

## Content

Research, mentoring, student and media information was gathered through the owner's academic materials, public professional sources and reviewed records. Private evaluations and email addresses of students must not be committed here. Verify future additions and any publication status before merging.

## Media

Optimized photos are in `assets/images/`; videos are in `assets/videos/`. Do not add unapproved personal or family photographs. Alt text and responsive photo layouts are in the HTML.
